# Pose Cognitive Trainer requirements

- Responsive installable web app for phones and PCs.
- Pose count: 1–10, default 4.
- Total active time: 1–240 seconds, default 120.
- Time between poses: 1–20 seconds, default 5.
- Five-second preparation countdown, excluded from active time.
- Every set contains each pose number exactly once in shuffled order.
- After a set, begin a newly shuffled set.
- Optional switch instruction after every completed set.
- One-second switch delay starts after the switch announcement finishes, has no visible countdown, and is excluded from active time.
- English and Hebrew spoken numbers and commands.
- If total time expires mid-set, complete that set and then finish.
- Start, pause/resume, and immediate stop/reset controls.
- Pausing freezes the active countdown and the current delay.
- Display the current pose prominently, active time remaining, set progress, and session state.
- Remember settings locally.
- Attempt to hold a screen wake lock during the session.
- Work offline after caching; packaged recordings are preferred for guaranteed offline speech.
